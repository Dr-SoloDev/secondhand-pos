## SECTION 1: SALES ENGAGEMENT PLAN

### 1.1 สิ่งที่ Sales ต้องรู้ก่อนออกขาย

**กฎหมาย ม.357 (ต้องเข้าใจลึก)**
- โทษ: จำคุกสูงสุด 5 ปี + ปรับ 100,000 บาท
- ต้องบันทึก: ชื่อ-นามสกุล, เลขบัตรประชาชน, สินค้า, ราคา, วันที่
- ตำรวจขอตรวจ records ได้ทุกเมื่อ — สมุดมือเขียนไม่ผ่าน

**Features หลัก:**

| Feature | คำอธิบายสำหรับลูกค้า |
|---|---|
| ม.357 Compliance Mode | บันทึกอัตโนมัติ + พิมพ์ใบรับซื้อ audit trail ได้ทันที |
| FIFO Inventory | ของที่เข้าก่อนออกก่อน — กำไรคำนวณถูกต้อง |
| Multi-Branch (4 สาขา) | ดูทุกสาขาจากหน้าจอเดียว + โอน stock ระหว่างสาขา |
| Price Tiers | ราคาตามปริมาณ — ระบบคำนวณให้เอง |
| Photo PO | ถ่ายรูปของแนบ PO ได้ทันที ไม่ต้อง LINE แยก |
| Reports | กำไร-ขาดทุน รายวัน/เดือน/ปี ส่งนักบัญชีได้เลย |

### 1.2 Sales Pitch

**Opening Hook (30 วินาที):**
> "พี่รู้ไหมว่าร้านรับซื้อของเก่าที่ไม่มีระบบบันทึกดิจิทัล มีโอกาสโดนจับตาม ม.357 — จำคุก 5 ปี scrap-pos record อัตโนมัติ ตำรวจมาขอตรวจ เปิดให้ดูได้ใน 10 วินาที"

**Closing:**
> "ร้านปิดใน 1 ปีถ้าไม่มี compliance — เราไม่ได้ขาย software เราขายความอุ่นใจ และโอกาสที่ร้านพี่จะอยู่ได้อีก 10 ปี"

**Pain Points → Solutions:**

| Pain Point | Solution |
|---|---|
| "กลัวตำรวจมาตรวจ" | บันทึก ม.357 อัตโนมัติ พิมพ์รายงานได้ทันที |
| "ไม่รู้กำไรจริงเท่าไหร่" | FIFO + รายงาน real-time |
| "หลายสาขาดูข้อมูลยาก" | Dashboard รวมทุกสาขา |
| "ราคาซับซ้อน จำไม่ไหว" | Price Tiers — กำหนดล่วงหน้า ระบบคำนวณให้ |
| "นักบัญชีขอรายงาน" | Export ได้ทันที |

### 1.3 Ideal Customer Profile (ICP)

| เกณฑ์ | รายละเอียด |
|---|---|
| ประเภทร้าน | รับซื้อของเก่า/เศษโลหะ/รีไซเคิล ที่รับซื้อจาก "คน" |
| ขนาด | 1-5 สาขา, ยอดซื้อ 50k–2M บาท/เดือน |
| ปัญหาปัจจุบัน | ใช้สมุดมือเขียน หรือ Excel — ไม่ผ่าน audit |
| พื้นที่เริ่มต้น | กรุงเทพฯ ปริมณฑล → เมืองใหญ่ (เชียงใหม่, ขอนแก่น, ชลบุรี) |

**ลูกค้าที่ยังไม่เหมาะ (Phase 1):**
- B2B เท่านั้น (ไม่มีผู้ขายรายบุคคล)
- มากกว่า 10 สาขา
- ไม่มี internet
