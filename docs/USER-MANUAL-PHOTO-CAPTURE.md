## 1. ภาพรวมฟีเจอร์

ระบบ **Photo Capture** ช่วยให้พนักงานสามารถถ่ายรูปสินค้าและบัตรประชาชนผู้ขาย **ในขั้นตอนการรับซื้อ** ได้ทันที โดยไม่ต้องใช้มือถือแยก หรือส่งรูปทีหลัง

### สิ่งที่ทำได้
- ✅ **ถ่ายรูปสินค้า** — ถ่ายรูปของที่รับซื้อแต่ละรายการผ่านเว็บแคม หรือเลือกจากแกลเลอรี
- ✅ **ถ่ายรูปบัตรประชาชน** — ถ่ายรูปบัตรผู้ขายตอนเพิ่มผู้ขายใหม่
- ✅ **อัปโหลดอัตโนมัติ** — รูปทั้งหมดถูกอัปโหลดขึ้นเซิร์ฟเวอร์เมื่อบันทึกใบรับซื้อ
- ✅ **ไม่ต้องใช้มือถือ** — ใช้กล้องเว็บแคมบนโต๊ะ หรือ กล้องหลังแท็บเล็ต ได้เลย

## 2. อุปกรณ์ที่รองรับ

| อุปกรณ์ | วิธีถ่ายรูป | วิธีเลือกรูป |
|:--------|:-----------|:------------|
| 💻 **คอมพิวเตอร์ตั้งโต๊ะ** | ใช้เว็บแคม (Webcam) | เลือกไฟล์จากเครื่อง |
| 📟 **แท็บเล็ต (iPad/Android)** | ใช้กล้องหลังแท็บเล็ต | เลือกจากแกลเลอรี |
| 📱 **มือถือ (เข้าผ่านเบราว์เซอร์)** | ใช้กล้องมือถือ | เลือกจากคลังรูป |

## 3. วิธีถ่ายรูปสินค้า

### ขั้นตอนที่ 1: เพิ่มสินค้าในใบรับซื้อ

1. เปิดหน้า **รับซื้อของเก่า** (Purchase Orders)
2. Layout top row: `[ค้นหาผู้ขาย] [บิล1/2/3] [สาขา] [+ผู้ขายใหม่]`
3. **บิล1 ถูกเลือกให้อัตโนมัติ** — ถ้าใช่ไม่ต้องกดอะไร
4. พิมพ์ชื่อหรือรหัสสินค้า → **ถ้าผลลัพธ์เดียว auto-select** → ใส่น้ำหนัก ราคา → กด **"+ เพิ่ม"**

### ขั้นตอนที่ 2: ถ่ายรูปสินค้า

มี 2 วิธีในการถ่ายรูป:

#### วิธี A: ใช้ปุ่ม FAB (ปุ่มกล้องลอย) 📷

```
 ┌──────────────────────────────────────────────┐
 │  [ค้นหาผู้ขาย...] [บิล1|บิล2|บิล3] [สาขา] [+ผู้ขายใหม่] │
 ├──────────────────────────────────────────────┤
 │  [รายการสินค้า...]               [+ เพิ่ม]    │
 │                                              │
 │  ┌─────────── ตารางสินค้า ───────────┐       │
 │  │ # │ สินค้า │ นน. │ รวม │📷│       │       │
 │  │ ── ─────── ───── ───── ─── │       │       │
 │  │ 1 │ เหล็ก   │ 100  │ ฿50 │✓│       │       │ ← ✓ = ถ่ายแล้ว
 │  │ 2 │ ทองแดง  │ 50   │ ฿80 │+│       │       │ ← + = ยังไม่ถ่าย
 │  └──────────────────────────────┘       │
 │                                         │
 │           [📸 1 รูป] ← Photo Strip      │
 │                                         │
 │                ┌─────┐                  │
 │                │ 📷  │ ← FAB            │
 │                └─────┘                  │
 └──────────────────────────────────────────┘
```

1. กดปุ่ม **📷** (FAB) ที่มุมขวาล่างของหน้าจอ
2. จะมี **Bottom Sheet** ขึ้นมาให้เลือก:

```
┌──────────────────────────────┐
│                              │
│       ═══ (手柄) ═══        │
│                              │
│      เพิ่มรูปภาพ              │
│                              │
│   ┌─────────────────────┐    │
│   │ 📷  ถ่ายรูป          │    │ ← เปิดกล้องถ่ายรูป
│   │     ใช้กล้องเว็บแคม   │    │
│   ├─────────────────────┤    │
│   │ 🖼️  เลือกรูป         │    │ ← เลือกจากเครื่อง/แกลเลอรี
│   │     เลือกจากแกลเลอรี │    │
│   ├─────────────────────┤    │
│   │ ✕  ยกเลิก           │    │ ← ปิด
│   └─────────────────────┘    │
└──────────────────────────────┘
```

#### วิธี B: ใช้ปุ่ม "+" ในแถวสินค้า

1. ในตารางสินค้า จะมีคอลัมน์ **📷** อยู่ด้านขวาสุด
2. กดปุ่ม **"+"** ในแถวที่ต้องการถ่ายรูป
3. เลือก **📷 ถ่ายรูป** หรือ **🖼️ เลือกรูป**
4. รอระบบจัดการที่เหลือ!

### ขั้นตอนที่ 3: ถ่ายรูป (Camera Mode)

```
┌──────────────────────────────────┐
│  📷 ถ่ายรูป                  ✕   │ ← กด ✕ เพื่อปิด
├──────────────────────────────────┤
│                                  │
│         ┌────────────┐           │
│         │            │           │
│         │  ภาพจาก     │           │
│         │  กล้อง      │           │
│         │            │           │
│         └────────────┘           │
│                                  │
│                                  │
│             (🔵 Capture)         │ ← กัดปุ่มกลมเพื่อถ่าย
│                                  │
├──────────────────────────────────┤
│                                  │
└──────────────────────────────────┘
```

1. จัดตำแหน่งสินค้าให้อยู่ในกรอบ
2. กดปุ่ม **Capture (วงกลมสีขาว)** ขนาดใหญ่
3. จะมีไฟแฟลชกระพริบ (feedback ว่าถ่ายแล้ว)
4. ระบบจะแสดง **Preview** ให้ตรวจสอบ:

```
┌──────────────────────────────────┐
│                                  │
│         ┌────────────┐           │
│         │            │           │
│         │  รูปที่ถ่าย  │           │
│         │  (Preview)  │           │
│         │            │           │
│         └────────────┘           │
│                                  │
│     [⟳ ถ่ายใหม่]    [✓ ใช้รูปนี้] │
│                                  │
└──────────────────────────────────┘
```

- ถ้าพอใจ → กด **✓ ใช้รูปนี้** ✅
- ถ้าไม่พอใจ → กด **⟳ ถ่ายใหม่** เพื่อถ่ายอีกครั้ง

### ขั้นตอนที่ 4: ตรวจสอบรูปที่ถ่าย

- ปุ่ม **"+"** จะเปลี่ยนเป็น **"✓" สีเขียว** ในแถวที่ถ่ายรูปแล้ว
- ด้านล่างของตารางสินค้า จะมี **Photo Strip** แสดงรูปทั้งหมดที่ถ่ายไว้
- กด **✕** ที่รูปใน Photo Strip เพื่อลบรูปนั้นทิ้ง
- ตัวเลขที่ **FAB (ปุ่มกล้องลอย)** จะบอกจำนวนรูปที่ถ่ายค้างไว้

## 4. วิธีถ่ายรูปบัตรประชาชนผู้ขาย

### ขั้นตอนที่ 1: เพิ่มผู้ขายใหม่

1. ที่หน้าใบรับซื้อ กดปุ่ม **"+ ผู้ขายใหม่"** (ด้านล่างซ้าย)
2. กรอกข้อมูล ชื่อ-นามสกุล, เบอร์โทร, เลขบัตรประชาชน

### ขั้นตอนที่ 2: ถ่ายรูปบัตร

```
┌──────────────────────────────────┐
│  เพิ่มผู้ขายใหม่                  │
├──────────────────────────────────┤
│                                  │
│  ชื่อ-นามสกุล [________________] │
│  เลขบัตร     [________________] │
│                                  │
│  ┌────────────────────────────┐  │
│  │ 📇 📸 เพิ่มรูปบัตรประชาชน  │  │ ← กดตรงนี้เพื่อถ่ายรูป
│  │    แตะเพื่อถ่ายรูป หรือ     │  │
│  │    เลือกรูป                │  │
│  └────────────────────────────┘  │
│                                  │
│  เบอร์โทร    [________________] │
│  ที่อยู่      [________________] │
│                                  │
├──────────────────────────────────┤
│     [ยกเลิก]        [บันทึก]     │
└──────────────────────────────────┘
```

1. กดที่พื้นที่ **"📸 เพิ่มรูปบัตรประชาชน"** (กรอบเส้นประ)
2. เลือก **📷 ถ่ายรูป** หรือ **🖼️ เลือกรูป** (เหมือนการถ่ายรูปสินค้า)
3. ถ่ายรูปบัตรให้ชัด — ระบบจะปรับขนาดอัตโนมัติ

### ขั้นตอนที่ 3: ตรวจสอบรูปบัตร

หลังจากถ่ายรูปบัตรแล้ว:

```
┌──────────────────────────────────┐
│  ┌────────────────────────────┐  │
│  │ ✅ ถ่ายรูปบัตรประชาชนแล้ว  │  │ ← กรอบเปลี่ยนเป็นสีเขียว
│  │    แตะเพื่อเปลี่ยนรูป      │  │
│  │    ┌────┐                 │  │
│  │    │รูป │                 │  │ ← รูปตัวอย่าง
│  │    └────┘                 │  │
│  └────────────────────────────┘  │
└──────────────────────────────────┘
```

- กรอบเปลี่ยนเป็น **สีเขียว** แสดงว่าถ่ายรูปแล้ว
- มี **รูปตัวอย่าง** ขนาดเล็กให้เห็น
- แตะที่รูปเพื่อ **ลบ** หรือ **เปลี่ยนรูปใหม่**
- ถ้าไม่อยากถ่ายรูปบัตร ก็ข้ามได้ (ไม่บังคับ)

### ขั้นตอนที่ 4: บันทึกผู้ขาย

กด **"บันทึก"** → ระบบจะ:
1. ✨ สร้างผู้ขายใหม่ในระบบ
2. 📤 อัปโหลดรูปบัตรประชาชนขึ้นเซิร์ฟเวอร์
3. ✅ เลือกผู้ขายนั้นในใบรับซื้อโดยอัตโนมัติ

## 5. การทำงานหลังบันทึกใบรับซื้อ

เมื่อกดปุ่ม **"บันทึกใบรับซื้อ"** ระบบจะทำงานดังนี้:

### Step 1: สร้างใบรับซื้อ
ระบบบันทึกข้อมูล PO → ได้เลขที่ใบรับซื้อ

### Step 2: อัปโหลดรูปภาพ (อัตโนมัติ)
```
กำลังอัปโหลด 3 รูป...
████████░░░░░░░ 50%
```
- รูปทั้งหมดที่ถ่ายไว้ ถูกอัปโหลดทีละรูปโดยอัตโนมัติ
- มี **Progress Bar** แสดงความคืบหน้าที่ด้านบนของหน้าจอ
- มีข้อความแจ้งเตือนที่มุมล่าง

### Step 3: เสร็จสิ้น
```
✅ อัปโหลด 3 รูปเรียบร้อย
```
- ระบบแสดงใบเสร็จตรวจสอบ
- ข้อมูล + รูปสินค้าพร้อมใช้งาน

### จัดเก็บรูปภาพ
```
Server:
└── uploads/
    ├── purchase-orders/
    │   └── 2026/
    │       └── 06/
    │           ├── po_001_abc123.jpg
    │           ├── po_001_def456.jpg
    │           └── ...
    └── sellers/
        └── 2026/
            └── 06/
                └── seller_005_xyz789.jpg
```

## 6. การแก้ปัญหาเบื้องต้น

### ปัญหาที่ 1: "ไม่สามารถเปิดกล้องได้"

| สาเหตุ | วิธีแก้ |
|:-------|:--------|
| เบราว์เซอร์ยังไม่ให้สิทธิ์กล้อง | ก่อนใช้ครั้งแรก เบราว์เซอร์จะถาม "อนุญาตให้เว็บไซต์นี้ใช้กล้อง?" → กด **"อนุญาต"** |
| เว็บแคมไม่ได้เชื่อมต่อ | เช็คว่าเสียบสายเว็บแคมแล้ว หรือเปิดกล้องแท็บเล็ตแล้ว |
| เว็บแคมถูกโปรแกรมอื่นใช้อยู่ | ปิดโปรแกรมอื่นที่ใช้กล้อง (Zoom, Meet, ฯลฯ) |

> 💡 **ทางเลือก:** กด **🖼️ เลือกรูป** แทนการถ่ายรูป — เลือกไฟล์รูปจากเครื่องได้เลย

### ปัญหาที่ 2: "ไฟล์ใหญ่เกินไป"

- ระบบจำกัดไฟล์รูปไม่เกิน **10 MB** ต่อรูป
- ระบบจะปรับขนาดรูปให้อัตโนมัติ (resize) ถ่ายจากมือถือก็ใช้ได้
- ถ้ายังติดปัญหา ให้เลือกไฟล์ที่มีขนาดเล็กลง

### ปัญหาที่ 3: "พื้นที่จัดเก็บเต็ม"

- ถ้าพื้นที่เซิร์ฟเวอร์ใกล้เต็ม ระบบจะแจ้งเตือน
- ติดต่อผู้ดูแลระบบเพื่อเพิ่มพื้นที่

### ปัญหาที่ 4: อัปโหลดไม่สำเร็จ

- ระบบจะพยายามอัปโหลดรูปทั้งหมดโดยอัตโนมัติ
- ถ้าอัปโหลดไม่สำเร็จ (เช่น เน็ตหลุด) → **ให้ลองบันทึกใบรับซื้ออีกครั้ง**
- รูปที่ค้างจะถูกอัปโหลดใหม่เมื่อมีการบันทึก PO ในครั้งถัดไป

## 7. เคล็ดลับ

### 📌 สำหรับพนักงานหน้าร้าน

- **ถ่ายรูปสินค้าตอนชั่งน้ำหนัก** — จัดวางของให้เห็นชัด ถ่ายตอนของอยู่บนตาชั่ง
- **ถ่ายรูปบัตรผู้ขายครั้งแรกเท่านั้น** — ผู้ขายเดิมไม่ต้องถ่ายซ้ำ ระบบจำรูปไว้ให้
- **ใช้เว็บแคมถ่ายของชิ้นใหญ่** — ยกของให้ตรงกล้อง
- **ใช้มือถือ/แท็บเล็ตถ่ายของชิ้นเล็ก** — เข้าเบราว์เซอร์จากเครื่องนั้นเลย

### 📌 สำหรับเจ้าของร้าน

- รูปที่ถ่ายไว้ช่วย **ตรวจสอบคุณภาพของ** ที่รับซื้อ
- มีหลักฐานยืนยัน **ตัวตนผู้ขาย** ผ่านรูปบัตรประชาชน
- ข้อมูลรูปถูกเก็บไว้ใน **เซิร์ฟเวอร์ของร้าน** (ไม่ผ่านบริษัทอื่น)
- รูปจะเชื่อมโยงกับ **เลขที่ใบรับซื้อ** ทำให้ค้นหาย้อนหลังได้ง่าย

### 📌 การดูแลรักษา

- เช็ดเลนส์เว็บแคมเป็นประจำ
- ตรวจสอบพื้นที่จัดเก็บเดือนละครั้ง
- อัปเดตเบราว์เซอร์ให้เป็นเวอร์ชันล่าสุด (รองรับ Chrome, Edge, Safari)
