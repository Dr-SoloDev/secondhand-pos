# คู่มือเริ่มใช้งานระบบ POS (สำหรับเจ้าของร้าน)

> ขั้นตอนเริ่มต้นครั้งแรก ตั้งค่าระบบแล้วเริ่มรับซื้อจริง — ทำทั้งหมดผ่านหน้าจอ ไม่ต้องแตะฐานข้อมูล
> ระบบ: รักษ์สะอาดรีไซเคิล (POS) — จ.สุรินทร์

---

## 1. ล็อกอินครั้งแรก

1. เปิดเบราว์เซอร์ → เข้า **`http://localhost:8080/index.html`** (หน้าเข้าสู่ระบบ)
2. กรอก:
   - ชื่อผู้ใช้: `admin`
   - รหัสผ่าน: `admin`
3. กด **เข้าสู่ระบบ** → เข้าสู่หน้าหลัก (Dashboard) ที่ `http://localhost:8080/admin/index.html`

> ⚠️ **สำคัญ:** รหัสผ่าน `admin/admin` เป็นรหัสเริ่มต้น ต้องเปลี่ยนทันที (ดูข้อ 2) ก่อนเปิดใช้พนักงานคนอื่น

---

## 2. เปลี่ยนรหัสผ่าน admin (ทำทันที)

> ระบบยังไม่มีหน้าเปลี่ยนรหัสผ่านของตัวเองแยกต่างหาก — ใช้หน้า "ผู้ใช้งาน" เปลี่ยนได้ (เจ้าของเป็น admin)

1. เมนูซ้าย → **ผู้ใช้งาน** (`http://localhost:8080/admin/users.html`)
2. หาแถวผู้ใช้ **admin** ในตารางรายชื่อผู้ใช้
3. กดปุ่ม **เปลี่ยนรหัสผ่าน** (ไอคอนในคอลัมน์ "จัดการ")
4. กรอกรหัสผ่านใหม่ 2 ครั้ง (**ขั้นต่ำ 12 ตัวอักษร**) → กด **เปลี่ยนรหัสผ่าน**
5. ทดสอบล็อกอินใหม่ด้วยรหัสที่ตั้งไว้

> หมายเหตุ: เมนู "โปรไฟล์" (มุมขวาบน) แก้ได้แค่ชื่อ-นามสกุล/เบอร์โทร — ยังไม่มีช่องเปลี่ยนรหัสผ่าน

---

## 3. ตั้งชื่อสาขา 1 และ 2

ระบบมี 2 สาขาเริ่มต้น: รหัส `BR01` (ชื่อ "สาขา 1") และ `BR02` (ชื่อ "สาขา 2") — ตั้งชื่อจริงได้เลย (รหัสสาขาแก้ไขไม่ได้)

1. เมนูซ้าย → **จัดการสาขา** (`http://localhost:8080/admin/branches.html`)
2. แถวสาขาแรก → กดปุ่ม **แก้ไข**
3. กรอก:
   - **ชื่อสาขา*** (จำเป็น) เช่น "สาขา 1 ตลาดเมืองสุรินทร์"
   - **ที่อยู่** / **เบอร์โทรศัพท์** / **ชื่อผู้จัดการ** (ไม่บังคับ)
4. กด **บันทึก** → ทำซ้ำกับสาขาที่ 2

---

## 4. ตั้งค่าชื่อร้าน + รายละเอียดใบเสร็จ

1. เมนูซ้าย → **ตั้งค่า** (`http://localhost:8080/admin/settings.html`)
2. หัวข้อ **ข้อมูลร้านค้า** กรอก:
   - **ชื่อร้าน** (แสดงบนใบเสร็จ)
   - **เบอร์โทรร้าน** / **ที่อยู่ร้าน**
    - **เลขประจำตัวผู้เสียภาษี** (13 หลัก — มีแล้วกรอก ไม่มีข้ามได้)
    - **เลขใบอนุญาตค้าของเก่า** (ใบเดียวทั้งกิจการ — จะแสดงบนชุดหลักฐานที่ส่งเจ้าหน้าที่ กรอกเมื่อสะดวกได้)
   - **ข้อความหัวบิล** เช่น "บริการดี ราคาดี ตาชั่งมาตรฐาน"
   - **อัตราภาษีเริ่มต้น (%)** (ค่าเริ่มต้น 7.00)
   - **สัญลักษณ์สกุลเงิน** (ค่าเริ่มต้น ฿)
   - **ข้อความท้ายใบเสร็จ** เช่น "ขอบคุณที่ใช้บริการ!"
3. กด **บันทึกการเปลี่ยนแปลง**
4. (แนะนำ) หัวข้อ **ค่าระบบ**: ตั้ง **รูปแบบวันที่** เป็น DD/MM/YYYY และ **ภาษาเริ่มต้น** เป็น Thai → **บันทึกการเปลี่ยนแปลง**

---

## 5. เพิ่มผู้ใช้และกำหนดสิทธิ์

1. เมนูซ้าย → **ผู้ใช้งาน** (`http://localhost:8080/admin/users.html`)
2. กดปุ่ม **+ เพิ่มผู้ใช้งาน**
3. กรอก: **ชื่อผู้ใช้*** (เปลี่ยนทีหลังไม่ได้), **เบอร์โทร***, **ชื่อ-นามสกุล***, **บทบาท***, **รหัสผ่าน*** (ขั้นต่ำ 12 ตัว), **สถานะ**, **สาขา**
4. กด **บันทึกผู้ใช้**

**บทบาทแต่ละระดับ:**
| บทบาท | ทำอะไรได้ |
|---|---|
| **admin** | ทุกอย่าง ทุกสาขา — จัดการผู้ใช้/สาขา/ตั้งค่าระดับร้าน/สำรองข้อมูล/ดูบันทึกการใช้งาน (ให้เฉพาะเจ้าของ) |
| **super_manager** | ดูแลหลายสาขา + จัดการผู้ใช้ระดับ cashier/manager |
| **manager** | ผู้จัดการประจำสาขา — ดูขาย Lot/สรุปธุรกิจ/พนักงาน, อนุมัติรายการ, ตั้งค่าระดับสาขา |
| **cashier** | พนักงานหน้าร้าน — รับซื้อของ (ใบรับซื้อ), ค้นผู้ขาย, เช็คสต็อก, เปิด-ปิดยอด |

> ผู้ใช้ระดับ manager/cashier **ต้องเลือกสาขา** (ผูกกับสาขาที่ประจำอยู่) — admin ไม่ผูกสาขา
> ลืมรหัสผ่าน? เจ้าของ/admin กดปุ่ม **รีเซ็ตรหัสผ่าน** ในหน้าเดียวกัน ระบบจะให้รหัสชั่วคราว (แสดงครั้งเดียว — คัดลอกแจ้งผู้ใช้ได้)

---

## 6. คีย์หมวดสินค้า (ทำก่อนคีย์รายการสินค้า)

1. เมนูซ้าย → **แคตตาล็อกสินค้า** (`http://localhost:8080/admin/catalog.html`)
2. กดปุ่ม **หมวดหมู่** → ระบบเปิดหน้าต่าง "จัดการหมวดหมู่"
3. กรอก **ชื่อหมวดหมู่*** เช่น "เหล็ก", "ทองแดง", "ขวดพลาสติก", "กระดาษ" (+ รายละเอียด ไม่บังคับ)
4. กด **บันทึกหมวดหมู่** → ทำซ้ำจนครบหมวดที่รับซื้อจริง → ปิดหน้าต่าง

---

## 7. คีย์รายการสินค้า + ราคา (บิล 1/2/3)

1. หน้า **แคตตาล็อกสินค้า** เดิม → กดปุ่ม **+ เพิ่มรายการ**
2. กรอก:
   - **รหัสสินค้า*** เช่น `WM01` (ใช้พิมพ์ค้นหาหน้ารับซื้อได้)
   - **ชื่อสินค้า*** เช่น "เครื่องซักผ้า"
   - **หมวดหมู่** (เลือกรายการที่คีย์ไว้ในข้อ 6)
   - **ราคาบิล 1 (ต่ำสุด)*** / **ราคาบิล 2 (กลาง)*** / **ราคาบิล 3 (สูงสุด)*** — ต่อ กก. ตามระดับราคาที่กำหนด
3. กด **บันทึก** → ทำซ้ำจนครบทุกรายการ

**ตรวจราคารวมทุกรายการ:** เมนูซ้าย → **บอร์ดราคา** (`http://localhost:8080/admin/price-board.html`) — ระบบแสดงราคารับซื้อแยกตามหมวด + ตัวเลือกสาขา และปุ่ม **พิมพ์บอร์ดราคา** ไว้ติดหน้าร้านได้
> หมายเหตุ: บอร์ดราคาเป็นหน้าแสดง/พิมพ์เท่านั้น — แก้ราคาให้กลับไปแก้ที่แคตตาล็อกสินค้า

---

## 8. เริ่มใช้งานจริง: ใบรับซื้อใบแรก

1. เมนูซ้าย → **รับซื้อของ** (`http://localhost:8080/admin/purchase-orders.html`)
2. เลือก **สาขา** (มุมขวาบนของฟอร์ม)
3. **เลือกผู้ขาย**: พิมพ์ชื่อ/เลขบัตรในช่องค้นหา → แตะชื่อผู้ขายที่ขึ้น / ถ้ายังไม่มี → กด **+ ผู้ขายใหม่** แล้วกรอกข้อมูล (ชื่อ-นามสกุลจำเป็น, บัตรประชาชน 13 หลัก, เบอร์โทร, ที่อยู่, ทะเบียนรถ)
4. เลือก **ระดับราคา (บิล)** 1/2/3 ตามที่ตกลงกับผู้ขาย
5. **เพิ่มรายการสินค้า**: พิมพ์รหัส/ชื่อสินค้า → เลือกจากรายการ → กรอก **น้ำหนัก (กก.)** → (ถ้ามี) **หักน้ำหนัก** → ระบบคำนวณราคาอัตโนมัติ → กด **+ เพิ่ม** → ทำซ้ำจนครบ
   - (แนะนำ) กด 📷 ถ่ายรูปสินค้าแต่ละรายการตาม พ.ร.บ.รับซื้อของเก่า
6. กรอก **วิธีจ่าย** (เงินสด/โอนธนาคาร), **ประเภทยานพาหนะ**, **ทะเบียนรถ**, **หมายเหตุ** (ไม่บังคับ)
7. ตรวจสอบยอดรวม → กด **บันทึกใบรับซื้อ** → ระบบให้ตรวจสอบรายการก่อนบันทึก → ติ๊ก "ฉันตรวจสอบข้อมูลแล้วว่าถูกต้อง" → กด **บันทึกใบรับซื้อ**
8. เปิดใบที่บันทึก → พิมพ์ใบเสร็จ (**พิมพ์ A4** หรือ **🖨️ พิมพ์ความร้อน**) มอบให้ผู้ขาย

> สินค้าโลหะมีค่า/ทองแดง: ระบบบังคับให้ผู้ขาย **เซ็นรับรอง** ว่าของได้มาโดยสุจริตก่อนบันทึก (ตาม ม.357)

---

## 9. บันทึกยินยอม PDPA ให้ผู้ขายเก่า + ชุดหลักฐานส่งเจ้าหน้าที่

> ผู้ขายที่ลงทะเบียนก่อนมีระบบ consent จะขึ้น "ยังไม่ได้ให้" — ไล่บันทึกให้ครบทีละคน

1. เมนูซ้าย → **จัดการผู้ขาย** → กด 🔍 เปิดดูผู้ขาย
2. แถว **PDPA** ถ้าขึ้น `-` → กดปุ่ม **✓ บันทึกความยินยอม** (ถามผู้ขายก่อนกด) → ขึ้นวันที่ยินยอมทันที (stamp ครั้งเดียว แก้ไม่ได้)
3. ทางเลือก: กด ✏️ แก้ไขผู้ขาย → ติ๊กช่องยินยอม → บันทึก

**ออกชุดหลักฐานให้ตำรวจ** (manager ขึ้นไปเท่านั้น):
1. หน้าเดียวกัน → ปุ่ม **🖨 ชุดหลักฐาน**
2. กล่องสีเหลือง: **ติ๊กเฉพาะบิลที่เป็นคดี** (อย่าเหมารวม — ศาลอาจนับต่างกรรมต่างวาระทุกบิล)
3. กด **โหลดชุดที่เลือก** → **พิมพ์ / บันทึก PDF** → ลงนาม+ประทับตรา → ส่งมอบ
4. ทุกครั้งที่เปิด/พิมพ์ ระบบบันทึก audit ไว้ (ดูได้ที่ **บันทึกการใช้งาน**)
5. บันทึกการส่งมอบ: ใน modal เดิม → **🔒 การเปิดเผยข้อมูล** → **＋ บันทึกการเปิดเผย** (ใครรับ/คดีอะไร/ส่งอะไรไปบ้าง)

รูปบัตรที่อัปโหลดใหม่จะมีลายน้ำ 45° ฝังในไฟล์อัตโนมัติ — ดูรายละเอียดฉบับเต็ม: `docs/SELLER-EVIDENCE-PACK.md`

## หมายเหตุท้าย

- **เพิ่มสาขาเพิ่มเติมทีหลังได้:** หน้า **จัดการสาขา** (`admin/branches.html`) → ปุ่ม **+ เพิ่มสาขา** → กรอก **รหัสสาขา** (กำหนดเอง เช่น `BR05`) + **ชื่อสาขา** → บันทึก
- **สำรองข้อมูลเป็นประจำ:** หน้า **ตั้งค่า** (`admin/settings.html`) → หัวข้อ "สำรองข้อมูลฐานข้อมูล" → **สร้างข้อมูลสำรอง** (ทุกครั้งก่อนปิดระบบวัน)
- **บันทึกการใช้งานระบบ** (log เข้า-ออกระบบ/การแก้ไข): หน้า **บันทึกการใช้งาน** (`admin/audit-log.html` — admin เท่านั้น)
- ติดปัญหา / สงสัยขั้นตอนใด → ติดต่อทีม IT/ผู้พัฒนาระบบ: **[ใส่เบอร์ติดต่อทีม IT]**
