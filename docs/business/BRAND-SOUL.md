## 1. ความจริงที่ถูกมองข้าม

ธุรกิจรับซื้อของเก่า — ร้านเล็กๆ ตามชายแดน, ตามต่างจังหวัด, ตรอกซอกซอยในเมือง

เป็นธุรกิจระดับล่างที่สังคมมองข้าม  
ไม่มีปากมีเสียง  
ถูกมองว่าเป็น "จำเลย" ของสังคม  
ถูกตัดสินไปแล้วตั้งแต่ยังไม่รู้ความจริงเบื้องหลัง  

**นี่คือโลกอีกใบที่ไม่มีใครอยากเข้าใจ**

ร้านเหล่านี้:
- ไม่มีทุนจ้างโปรแกรมเมอร์
- ใช้สมุดจดด้วยมือ
- เสี่ยงเจอของโจรโดยไม่รู้ตัว
- เสี่ยงถูกตำรวจจับทั้งที่บริสุทธิ์
- ลูกค้าที่เป็นคนจนขายของก็เสี่ยงโดนกล่าวหาว่าขโมย
- ไม่มีหลักฐาน ไม่มีระบบ ป้องกันตัวเองไม่ได้

## 2. สิ่งที่เราสร้าง

เราให้ **ระบบที่มีปากมีเสียง** กับคนเหล่านี้

ไม่ใช่แค่ POS — แต่เป็น:
- **หลักฐานป้องกันทุกฝ่าย** — ร้าน, ลูกค้า, ตำรวจ
- **เกราะป้องกันคนที่ไม่มีใครปกป้อง**
- **ศูนย์ข้อมูลลูกค้า (Seller Data Center)** — กดดูทีเดียวรู้ประวัติทั้งหมด + รูปถ่ายสินค้าทุกชิ้น
- **ระบบถ่ายรูปรายการสินค้า** — ไว้ยืนยันของต้องสงสัย, ไว้พิสูจน์ความบริสุทธิ์

**ประโยชน์ที่ได้:**

| ใคร | ได้อะไร |
|:----|:-------|
| ร้านรับซื้อ | ป้องกันความผิด, ทำงานง่ายขึ้น, ปฏิบัติตามกฎหมาย ม.357 |
| ลูกค้าที่บริสุทธิ์ | มีหลักฐานยืนยันตนเอง, ไม่ต้องเป็นแพะรับผิด |
| ลูกค้าที่ผิดจริง | ก็มีหลักฐานยืนยันความผิด — ยุติธรรมสำหรับทุกฝ่าย |
| ตำรวจ | ตรวจสอบง่ายขึ้น, ทำงานมีประสิทธิภาพ |
| สังคม | โลกน่าอยู่ขึ้น, ปลอดภัยขึ้น, มีความเป็นธรรมมากขึ้น |

## 3. วิสัยทัศน์

> "เราจะไม่หยุดให้โค้ดชุดนี้ช่วยแค่ที่นี่ที่ร้านนี้ที่เดียว"
> — Dr.solodev

ร้านอื่นอาจไม่มีทุนจ้างคนทำโปรแกรม  
แต่เราสร้างมันแล้ว — และเราจะนำมัน scale เป็นอีก 1 ธุรกิจ  
ในราคาที่ยุติธรรม

ระบบนี้จะ:
- ช่วยผู้คน
- ช่วยสังคม
- ช่วยประเทศ
- ช่วยโลกใบนี้

**ระบบนี้คือธุรกิจที่จำเป็นต้องมี**  
มันช่วยทั้งตัวเราให้อุดมสมบูรณ์  
และความปลอดภัยก็จะขยายตัวออกไป ส่งต่อไปเรื่อยๆ

## 4. แก่นของ Brand

| องค์ประกอบ | คำนิยาม |
|:-----------|:--------|
| **Mission** | ปกป้องคนที่ไม่มีปากมีเสียงในธุรกิจรับซื้อของเก่า |
| **Vision** | ทุกร้านรับซื้อของเก่ามีระบบป้องกันที่ยุติธรรม — ไม่ว่าร้านนั้นจะอยู่ที่ไหน |
