## 1. เริ่มต้นใช้งาน

### 1.1 การเข้าสู่ระบบ

1. เปิดเบราว์เซอร์ (Chrome / Edge / Safari)
2. ไปที่ `http://localhost:8080/admin/` (หรือโดเมนที่ตั้งไว้)
3. กรอกชื่อผู้ใช้และรหัสผ่าน
4. กด **เข้าสู่ระบบ**

![หน้าจอเข้าสู่ระบบ](placeholder-login.png)

### 1.2 ส่วนประกอบของระบบ

หน้าจอหลักประกอบด้วย:
- **แถบเมนูด้านซ้าย** — ลิงก์ไปยังฟีเจอร์ต่างๆ
- **เนื้อหาหลัก** — แสดงข้อมูลตามหน้าที่เลือก
- **แถบด้านบน** — ชื่อสาขา, ผู้ใช้ปัจจุบัน, ปุ่มออกจากระบบ

### 1.3 บทบาทผู้ใช้

| บทบาท | สิทธิ์ |
|--------|--------|
| admin | เข้าถึงทุกสาขา, จัดการผู้ใช้, ตั้งค่าระบบ |
| manager | จัดการสาขาที่สังกัด, สร้าง/ยกเลิก PO และ Sale Lot |
| cashier | รับซื้อสินค้า, ค้นหาผู้ขาย, ดูรายงาน |

## 2. การรับซื้อสินค้า (Purchase Orders)

### 2.1 สร้างใบรับซื้อใหม่

> **Layout top row (Tab order):** `[ค้นหาผู้ขาย] → [บิล1/2/3] → [สาขา] → [+ผู้ขายใหม่]`

1. ไปที่เมนู **รับซื้อ** > **สร้างใบรับซื้อ**
2. **ค้นหาผู้ขาย** — เป็นอันดับแรกเสมอ:
   - พิมพ์ชื่อ หรือหมายเลขบัตรประชาชน
   - เลือกจากรายการค้นหา
   - ถ้าเป็นผู้ขายใหม่: กด **+ ผู้ขายใหม่** (ปุ่มขวาสุด)
3. **เลือกบิลราคา** — ระบบเลือก **บิล1** ให้อัตโนมัติ:
   - ถ้าต้องการบิล2/บิล3 → กดเปลี่ยน
   - ถ้าใช้บิล1 → ไม่ต้องกดอะไร
4. เลือก **สาขา** (อัตโนมัติตามผู้ใช้)
5. เลือก **รายการสินค้า**:
   - พิมพ์ชื่อสินค้า (ระบบแนะนำจากแค็ตตาล็อก)
   - ✅ **ถ้าผลลัพธ์เดียว** → ระบบเลือกให้อัตโนมัติ + ข้ามไปน้ำหนัก
   - ระบุ **น้ำหนัก** (กก.) — คลิกที่ช่อง → select-all อัตโนมัติ พิมพ์ทับได้เลย
   - เลือก **ราคาตามบิล** (บิล1 auto)
   - กด **เพิ่มรายการ**
6. ตรวจสอบรายการในตาราง
7. กด **บันทึก**

> 💡 **Keyboard-first:** ใช้ Tab เพื่อข้ามระหว่างช่อง, Enter เพื่อยืนยัน — ไม่ต้องใช้เมาส์

### 2.2 การทำงานอัตโนมัติ

เมื่อบันทึกใบรับซื้อสำเร็จ ระบบจะ:
- ✅ เพิ่มสต็อกในหมวดหมู่
- ✅ อัปเดตประวัติผู้ขาย (จำนวนครั้ง + ยอดรวม)
- ✅ สร้างเลขที่อ้างอิง: `PO-{รหัสสาขา}-{วันที่}-{ลำดับ}`

### 2.3 ยกเลิกใบรับซื้อ

1. ไปที่เมนู **รับซื้อ** > **รายการรับซื้อ**
2. ค้นหาใบรับซื้อที่ต้องการ
3. กด **ยกเลิก**
4. ยืนยันการยกเลิก

ระบบจะคืนสต็อกอัตโนมัติ

### 2.4 พิมพ์ใบรับซื้อ

1. เปิดใบรับซื้อ
2. กด **พิมพ์**
3. ระบบแสดงหน้าพิมพ์ พร้อมข้อมูลใบรับซื้อ + รายการ + ราคา

### 2.5 การจัดการสินค้าที่ต้องมีใบรับ (โลหะมีค่า)

สำหรับหมวดหมู่ที่ต้องกรอกเลขบัตรประชาชน (ทองคำ นาฬิกา ฯลฯ):
- ระบบจะแจ้งเตือนให้กรอกเลขที่บัตร
- ใบรับซื้อจะถูกทำเครื่องหมายเป็น "ประเภทต้องรับรอง"

### 2.6 การถ่ายรูป

1. สร้างใบรับซื้อ → ได้เลขที่ PO
2. เปิดลิงก์ถ่ายรูป (QR code) บนมือถือ
3. ถ่ายรูปสินค้า
4. รูปจะเชื่อมกับใบรับซื้ออัตโนมัติ

## 3. การขาย Lot (Sale Lots)

### 3.1 สร้าง Sale Lot ใหม่

1. ไปที่เมนู **ขาย** > **สร้าง Sale Lot**
2. เลือก **สาขา**
3. กรอก **ชื่อผู้ซื้อ**
4. เลือก **วันที่ขาย**
5. เพิ่ม **รายการสินค้า**:
   - เลือกสินค้าจากแค็ตตาล็อก
   - ระบุ **น้ำหนัก** และ **ราคาขายต่อหน่วย**
   - เพิ่มรายการ
6. ระบุ **ค่าขนส่ง** (ถ้ามี)
7. กด **บันทึก**

ระบบจะ:
- ✅ คำนวณต้นทุน FIFO อัตโนมัติ
- ✅ ตัดสต็อก
- ✅ คำนวณกำไรขั้นต้น

### 3.2 สถานะ Sale Lot

| สถานะ | ความหมาย |
|--------|----------|
| confirmed | ยืนยันแล้ว — ตัดสต็อกแล้ว |
| cancelled | ยกเลิกแล้ว — คืนสต็อกแล้ว |

### 3.3 แก้ไข Sale Lot

- **confirmed:** ระบบจะคืนสต็อก → อัปเดตรายการ → ตัดสต็อกใหม่ (ใน transaction เดียวกัน)
- เปลี่ยนสถานะ Draft → Confirmed: กด **ยืนยัน**

### 3.4 ยกเลิก Sale Lot

1. เปิด Sale Lot ที่ต้องการ
2. กด **ยกเลิก**
3. ระบบคืนสต็อกอัตโนมัติ

### 3.5 บันทึกรายรับจริง

1. เปิด Sale Lot ที่ **confirmed**
2. กด **บันทึกรายรับจริง**
3. กรอกยอดเงินที่ได้รับจริง
4. ระบบคำนวณกำไรสุทธิ = รายรับจริง - ต้นทุน - ค่าใช้จ่าย

### 3.6 การคำนวณต้นทุน

ระบบรองรับ 2 วิธี (ตั้งค่าต่อสาขา):

| วิธี | คำอธิบาย |
|-----|----------|
| **FIFO** (ค่าเริ่มต้น) | ตัดสต็อกจาก PO ที่รับซื้อมาก่อน |
| **Weighted Average** | คำนวณต้นทุนถัวเฉลี่ยจากสต็อกคงเหลือ |

## 4. การจัดการผู้ขาย (Sellers)

### 4.1 เพิ่มผู้ขายใหม่

1. ไปที่เมนู **ผู้ขาย** > **เพิ่มผู้ขาย**
2. กรอกข้อมูล:
   - **ชื่อ-นามสกุล** (จำเป็น)
   - **หมายเลขบัตรประชาชน** (13 หลัก)
   - **เบอร์โทรศัพท์** (10 หลัก)
   - **ทะเบียนรถ** (ไม่บังคับ)
   - **ยอมรับ PDPA** (ต้องกดยอมรับ)
3. กด **บันทึก**

ระบบป้องกัน:
- ❌ บัตรประชาชนซ้ำ
- ❌ เบอร์โทรซ้ำ
- ❌ เลขบัตรไม่ครบ 13 หลัก

### 4.2 ค้นหาผู้ขาย

- พิมพ์ชื่อ หรือเลขบัตรประชาชน
- ระบบค้นหาแบบยืดหยุ่น (LIKE %query%)

### 4.3 จัดการบัญชีดำ (Blacklist)

1. ค้นหาผู้ขาย
2. กด **ขึ้นบัญชีดำ**
3. ระบุ **เหตุผล**
4. กดยืนยัน

ผู้ขายที่ถูกขึ้นบัญชีดำ:
- จะไม่แสดงในการค้นหาปกติ
- จะไม่สามารถขายสินค้าได้ (ระบบแจ้งเตือนตอนสร้าง PO)
- แสดงเครื่องหมายบัญชีดำในรายการ

### 4.4 ดูประวัติผู้ขาย

- กด **ประวัติ** เพื่อดู:
  - จำนวนครั้งที่มาขาย
  - ยอดรวมที่ขายได้
  - รายการใบรับซื้อทั้งหมด
  - รูปถ่ายสินค้า

### 4.5 Data Center

ศูนย์รวมข้อมูลผู้ขาย:
- ข้อมูลส่วนตัว
- สรุปยอดขายทั้งหมด
- รายการ PO + รูปถ่าย
- สถิติ

## 5. การโอนสต็อก (Stock Transfers)

### 5.1 สร้างการโอน

1. ไปที่เมนู **โอนสต็อก** > **สร้างการโอน**
2. เลือก:
   - **สาขาต้นทาง**
   - **สาขาปลายทาง**
   - **หมวดหมู่สินค้า**
   - **น้ำหนัก** (กก.)
   - ข้อมูลขนส่ง (ผู้ขนส่ง, ทะเบียนรถ, คนขับ)
3. กด **บันทึก**

### 5.2 ยืนยันการโอน

1. เปิดการโอนที่สถานะ **pending**
2. กด **ยืนยัน**
3. ระบบหักสต็อกจากสาขาต้นทาง + เพิ่มสต็อกที่สาขาปลายทาง

### 5.3 ยกเลิกการโอน

1. เปิดการโอน
2. กด **ยกเลิก**
3. ระบบคืนสต็อกที่สาขาต้นทาง

## 6. แดชบอร์ดและรายงาน (Dashboard & Reports)

### 6.1 หน้าแรก (Dashboard)

แสดง:
- **สถิติสรุป:** ยอดซื้อวันนี้, ยอดขายวันนี้, กำไร, สต็อกคงเหลือ
- **กราฟ Sale Lot:** แสดงยอดขายแต่ละเดือน
- **Sale Lot ล่าสุด:** ตารางรายการขายล่าสุด 5 รายการ

### 6.2 รายงาน

| รายงาน | รายละเอียด |
|--------|------------|
| รายงานรับซื้อ | ดู/ส่งออก CSV — กรองตามสาขา, วันที่, ผู้ขาย |
| รายงาน Sale Lot | ดู/ส่งออก CSV — แยกตามสาขา, สถานะ |
| กราฟ Sale Lot | ข้อมูลกราฟสำหรับ dashboard |
| สรุปการเงิน | ยอดขาย, ค่าใช้จ่าย, ยอดรับซื้อ, น้ำหนัก |
| ส่งออก CSV | ดาวน์โหลดข้อมูลการเงินเป็น CSV |

## 7. การจัดการสินค้าคงคลัง (Inventory)

### 7.1 หมวดหมู่สินค้า

- สร้าง แก้ไข ลบ หมวดหมู่
- ตั้งค่า:
  - **ชื่อหมวดหมู่** (ซ้ำไม่ได้)
  - **สาขา**
  - **หน่วยนับ** (กก. / ชิ้น)
  - **ราคาขาย**
  - **เกณฑ์แจ้งเตือนสต็อก** (เมื่อสต็อกต่ำกว่า)
  - **ต้องใช้ใบรับ (โลหะมีค่า)**

### 7.2 สินค้าคงคลัง

- ดูสต็อกคงเหลือแยกตามหมวดหมู่
- ตั้งราคาขาย
- กำหนดเกณฑ์แจ้งเตือน

### 7.3 ราคาตามบิล

ระบบรองรับ 3 ระดับราคาต่อหมวดหมู่:
- **บิล1** (ราคาปกติ)
- **บิล2** (ราคาปานกลาง)
- **บิล3** (ราคาพิเศษ)

## 8. การจัดการพนักงาน (Employees)

### 8.1 เพิ่มพนักงาน

1. ไปที่เมนู **พนักงาน**
2. กด **เพิ่มพนักงาน**
3. กรอกชื่อ, สาขา, ตำแหน่ง
4. กดบันทึก

### 8.2 สร้างค่าใช้จ่ายเงินเดือน

1. เลือกพนักงาน
2. กด **สร้างค่าใช้จ่ายเงินเดือน**
3. ระบบสร้างรายการค่าใช้จ่ายในเดือนปัจจุบัน

### 8.3 สร้างค่าใช้จ่ายประกันสังคม

1. เลือกพนักงาน  
2. กด **สร้างค่าใช้จ่าย ประกันสังคม**
3. ระบบสร้างรายการค่าใช้จ่ายประกันสังคม

## 9. ค่าใช้จ่ายธุรกิจ (Business Expenses)

### 9.1 เพิ่มค่าใช้จ่าย

1. ไปที่เมนู **การเงิน** > **ค่าใช้จ่าย**
2. กด **เพิ่มค่าใช้จ่าย**
3. ระบุ: สาขา, วันที่, หมวดหมู่, จำนวนเงิน, รายละเอียด
4. กดบันทึก

### 9.2 ดูรายการ

- รายการค่าใช้จ่ายทั้งหมดในระบบ
- รวมยอดค่าใช้จ่ายแยกตามสาขา

## 10. การตั้งค่า (Settings)

### 10.1 ร้านค้า

- ตั้งค่าชื่อร้าน, ที่อยู่, เบอร์โทร
- เลือกวิธีการคำนวณต้นทุน (FIFO / Weighted Average)
- ตั้งค่าราคาตามบิล

### 10.2 ผู้ใช้

- จัดการผู้ใช้ระบบ
- กำหนดบทบาท (admin / manager / cashier)
- เปลี่ยนรหัสผ่าน

### 10.3 สำรองข้อมูล

- สร้าง **Backup** ปัจจุบัน
- **กู้คืน** จาก Backup
- ดูประวัติการ Backup
- ดาวน์โหลด / ลบ Backup

## 11. การแก้ไขปัญหาเบื้องต้น

| ปัญหา | สาเหตุ | วิธีแก้ |
|-------|--------|--------|
| ล็อกอินไม่ได้ | รหัสผ่านผิด / JWT หมดอายุ | ลองใหม่ / ติดต่อ Admin |
| "Too many login attempts" | พยายามล็อกอินผิดหลายครั้ง | รอ 15 นาที |
| หาผู้ขายไม่เจอ | ผู้ขายถูกขึ้นบัญชีดำ | ใช้ `include_blacklisted=true` |
| สร้างใบรับซื้อไม่ได้ | สินค้าต้องใช้ใบรับ | กรอกเลขบัตรประชาชน |
| สร้าง Sale Lot ไม่ได้ | สต็อกไม่พอ | ตรวจสอบสต็อกคงเหลือ |
| ยกเลิก PO ไม่ได้ | สินค้าถูกขายไปแล้ว | ติดต่อ Admin |
| ข้อมูลไม่ขึ้น | cache เบราว์เซอร์ | รีเฟรชหน้า (F5) |
| พิมพ์ไม่ได้ | ไม่มีเครื่องพิมพ์ | ตั้งค่าเครื่องพิมพ์ในเบราว์เซอร์ |
