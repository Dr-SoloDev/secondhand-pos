# คู่มือชุดหลักฐานผู้ขาย (Seller Evidence Pack) — สำหรับร้าน

> เอกสารฉบับนี้สำหรับเจ้าของ/ผู้จัดการร้าน — วิธีเตรียมเอกสารส่งตำรวจ/ทนาย/ศาล จากระบบ POS

## 1. ตั้งค่าครั้งเดียว (เจ้าของร้านทำ)

1. **เลขใบอนุญาตค้าของเก่า** — เมนู **ตั้งค่า** → หัวข้อข้อมูลร้านค้า → ช่อง **เลขใบอนุญาตค้าของเก่า** → บันทึก (ใบเดียวทั้งกิจการ กรอกเมื่อสะดวกได้)
2. **ไล่บันทึกยินยอม PDPA ให้ผู้ขายเก่า** — เมนู **จัดการผู้ขาย** → เปิดดูผู้ขาย → ถ้าแถว PDPA ขึ้น `-` ให้กด **✓ บันทึกความยินยอม** (ถามผู้ขายก่อนกด) — stamp ครั้งเดียว

## 2. ออกชุดหลักฐานส่งเจ้าหน้าที่ (manager ขึ้นไปเท่านั้น)

1. **จัดการผู้ขาย** → 🔍 เปิดดูผู้ขาย → ปุ่ม **🖨 ชุดหลักฐาน**
2. กล่องสีเหลือง **☑ เลือกบิลที่รวมในชุดหลักฐาน**:
   - ⚖️ **ติ๊กเฉพาะบิลที่เป็นคดี** — อย่าเหมารวมทุกบิล เพราะศาลอาจนับต่างกรรมต่างวาระแยกกันทุกบิล ทำให้ผู้ขายรับโทษเกินจริง
   - กด **โหลดชุดที่เลือก** (เปลี่ยนใจได้ กดใหม่ได้เรื่อยๆ)
3. ตรวจเอกสารบนจอ: หัวร้าน+ใบอนุญาต → ข้อมูลผู้ขาย+รูปบัตร (มีลายน้ำ) → ประวัติธุรกรรมพร้อมรูปของ → ผลตรวจ hash chain (ต้องเขียว "ไม่ถูกดัดแปลง") → disclosure log
4. กด **พิมพ์ / บันทึก PDF** → **ลงนาม 2 ช่อง + ประทับตราร้าน** → ส่งมอบ
5. ถ้า badge ขึ้นแดง "พบการแก้ไข" — **หยุด อย่าส่ง** ติดต่อทีม IT ทันที

## 3. บันทึกการส่งมอบ (ทุกครั้ง ห้ามลืม)

ใน modal ผู้ขายเดิม → **🔒 การเปิดเผยข้อมูล** → **＋ บันทึกการเปิดเผย** กรอก:
- **ผู้รับข้อมูล** (เช่น สว.สทภ.1 สน.เมือง / เลขคดี)
- **วัตถุประสงค์** (เช่น ตรวจสอบของกลางคดี 147/2569)
- **ข้อมูลที่เปิดเผย** (ติ๊ก: เลขบัตร/รูปบัตร/ธุรกรรม/...)
- **ฐานกฎหมาย** (เช่น ม.24(3)) + บันทึกเพิ่มเติม (เช่น ส่งสำเนา 2 ฉบับ ลงนามรับแล้ว)

> บันทึกนี้ลบ/แก้ไม่ได้ — เป็นหลักฐานว่าร้านส่งอะไรให้ใครเมื่อไหร่

## 4. เรื่องรูปบัตร (watermark)

- รูปที่อัปโหลดใหม่มีลายน้ำ 45° ฝังในไฟล์อัตโนมัติ (ข้อความ + คำรับรองที่มา)
- รูปเก่า backfill แล้วทั้งระบบ (ต้นฉบับสำรองใน `uploads/sellers/_pre-watermark-backup/`)
- ถ้าอัปโหลดแล้วไม่มีลาย (เช่น ตัวหนังสือไม่ขึ้น) แจ้ง IT — ระบบจะข้ามแบบ fail-open แล้วจด log ไว้

## 5. งาน ops (ทีม IT)

```bash
# ตรวจ chain ทั้งระบบ
docker compose exec -T web php /var/www/customizations/scripts/integrity-backfill.php
# backfill ลายน้ำรูปเก่า (idempotent, มี backup)
php scripts/watermark-backfill.php            # dry-run: เติม --dry-run
# ดูว่าใครเปิดชุดหลักฐาน/รวมบิลอะไรบ้าง
# → ตาราง activity_log action='view_evidence_pack' (after_json มี po_filter/included_refs)
```

- `SELLER_ID_ENCRYPTION_KEY` ใน `.env` ห้ามหาย/ห้ามเปลี่ยนมั่ว — ใช้ถอดบัตร + เป็นต้นทาง key ของ hash chain (ดู `docs/runbooks/SELLER-ID-ENCRYPTION.md`)
- ใบอนุญาต/ความยินยอม/chain ขยายคลุมบิล (PO) ยังไม่ทำ — รอเฟสถัดไป
