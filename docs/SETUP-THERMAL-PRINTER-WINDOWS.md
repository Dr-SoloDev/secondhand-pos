# 🖨️ คู่มือติดตั้งเครื่องพิมพ์ความร้อน (Thermal) — Windows PC แต่ละสาขา

> ใช้ติดตั้ง **1 ครั้งต่อเครื่องคอมพิวเตอร์ Windows** ของแต่ละสาขา
> เครื่องพิมพ์: **EasyPrint ES-8804** (หรือรุ่นตระกูล 880x) — ต่อสาย USB กับคอมเครื่องนี้
> เวลาทำทั้งหมด: ~20 นาที/เครื่อง — ทำเสร็จแล้วแจ้งทีมงานเพื่อตั้งค่า IP ในระบบ

---

## เตรียมของ (ก่อนเริ่ม)

- [ ] คอมพิวเตอร์ Windows ที่เครื่องพิมพ์ความร้อนต่ออยู่ (เปิดเครื่อง + login)
- [ ] เครื่องพิมพ์ EasyPrint ES-8804 ต่อสาย USB กับคอมเครื่องนี้ **และเปิดไฟ**
- [ ] กระดาษม้วนความร้อนอยู่ในเครื่อง (ขนาด 80mm)
- [ ] อินเทอร์เน็ตใช้งานได้ (โหลด driver)
- [ ] โฟลเดอร์ `print-server` จากทีม (ไฟล์ชุดติดตั้ง — ถ้ายังไม่มี แจ้งทีมงาน)

---

## ขั้นตอนที่ 1 — ติดตั้ง Driver เครื่องพิมพ์ (ครั้งแรกเท่านั้น)

> ถ้า Windows เห็นเครื่องพิมพ์ชื่อ "EasyPrint ES-8804" อยู่แล้วในหน้าพิมพ์ → ข้ามไปขั้นตอนที่ 2 ได้

1. เปิดเว็บเบราว์เซอร์ ไปที่: **https://easyprinterthailand.com/driveresthermalprinter/**
2. ดาวน์โหลด Driver ของตระกูล **8803 / 8804 / 8805 / 5852** (ใช้ตัวเดียวกันทั้งหมด — ถ้าไม่แน่ใจโหลดตัว ES-8804/880x)
3. แตก zip (ถ้าเป็น zip) แล้วรันไฟล์ติดตั้ง (Setup.exe หรือคล้าย) — กด Next/Install ไปเรื่อยๆ ตามค่าเริ่มต้น
4. เมื่อติดตั้งเสร็จ **เสียบสาย USB เครื่องพิมพ์ค้างไว้** — Windows ควรติดตั้ง driver ให้อัตโนมัติ
5. ทดสอบ:
   - กดปุ่ม **Start (Windows)** → พิมพ์ `printers` → เปิด **Printers & scanners**
   - ควรเห็นเครื่องพิมพ์ชื่อ **"EasyPrint ES-8804"** (หรือคล้าย)
   - คลิกที่ชื่อเครื่องพิมพ์ → **Print test page** → ต้องมีข้อความทดสอบออกจากเครื่องพิมพ์ ✅
6. **จำชื่อเครื่องพิมพ์ให้ตรงตัว** (จดไว้) — จะใช้ในขั้นตอนที่ 3

---

## ขั้นตอนที่ 2 — วางโฟลเดอร์ print-server

1. รับโฟลเดอร์ `print-server` จากทีม (ไฟล์ zip หรือ copy มาจาก USB/แชร์ไฟล์)
2. วางไว้ที่ตำแหน่งถาวร เช่น `C:\print-server` (**ห้ามวางบน Desktop แล้วย้ายภายหลัง** — ต้องอยู่ที่เดิม)
3. เปิดโฟลเดอร์ — ควรเห็นไฟล์:
   - `install.bat` ← ตัวติดตั้ง (คลิกอันนี้)
   - `print_server_http.py`
   - `print_receipt.py`
   - อื่นๆ (start.sh, test ฯลฯ — ไม่ต้องแตะ)

---

## ขั้นตอนที่ 3 — รันตัวติดตั้ง install.bat

1. **ดับเบิลคลิก `install.bat`** (ถ้า Windows ถาม "ต้องการให้แอปนี้เปลี่ยนแปลงอุปกรณ์นี้ไหม" → กด **Yes**)
2. หน้าต่างสีดำจะทำงานเอง:
   - ตรวจ Python (ถ้าไม่มี → หน้าจอจะบอกวิธีติดตั้ง — ทำตามแล้วรันใหม่)
   - ติดตั้ง library (ครั้งแรก ~1-2 นาที รอจนขึ้นข้อความผ่าน)
3. ถึงขั้นตอน **เลือกเครื่องพิมพ์** → พิมพ์ชื่อเครื่องพิมพ์จากขั้นตอนที่ 1
   - (กด Enter ล้วนๆ = ใช้ชื่อ "EasyPrint ES-8804" อัตโนมัติ)
4. รอ **ทดสอบพิมพ์ Test Page** — กระดาษต้องออกมาเป็นบิลทดสอบ ✅
5. ตัวติดตั้งจะตั้งค่า **เปิดอัตโนมัติเมื่อเปิดเครื่อง Windows** ให้เรียบร้อย
6. ปิดหน้าต่าง (กดปุ่มใดก็ได้)

---

## ขั้นตอนที่ 4 — ตรวจว่าพร้อมใช้งาน

1. เปิดเบราว์เซอร์ เปิด URL: `http://127.0.0.1:9120/health`
2. ควรเห็นข้อความ JSON:
   ```json
   {"status":"success","printer":"EasyPrint ES-8804","printer_ok":true,"message":"Print Server Ready"}
   ```
3. ถ้า `printer_ok: false` → ตรวจว่าเครื่องพิมพ์เปิดอยู่ + ต่อ USB + ชื่อในขั้นตอนที่ 3 ถูกต้อง

---

## ขั้นตอนที่ 5 — หา IP ของคอมเครื่องนี้ (แจ้งทีม)

1. กด **Windows + R** → พิมพ์ `cmd` → Enter
2. พิมพ์: `ipconfig` → Enter
3. หาบรรทัด **IPv4 Address** (เช่น `192.168.1.50`)
4. **แจ้ง IP นี้ + ชื่อเครื่องพิมพ์ ให้ทีมงาน** — ทีมจะตั้งค่าในระบบ (หน้า "จัดการสาขา") ให้เสร็จ

---

## ขั้นตอนที่ 6 — ทดสอบพิมพ์จากระบบจริง

1. ทีมยืนยันว่าตั้งค่าในระบบเรียบร้อยแล้ว
2. เปิดระบบ POS → **รับซื้อของ** → บันทึกใบรับซื้อ (หรือเปิดใบเดิม)
3. กดปุ่ม **"ความร้อน" (พิมพ์ทันที)** ในหน้าบิล
4. บิลต้องออกจากเครื่องพิมพ์ความร้อน ✅

---

## การแก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---|---|---|
| Test page ไม่พิมพ์ (ขั้นตอน 1) | driver ไม่ตรง / สาย USB | ติดตั้ง driver ใหม่ / ลองเปลี่ยนสาย / เสียบพอร์ต USB อื่น |
| install.bat บอกไม่พบ Python | ยังไม่ติดตั้ง Python | ทำตามคำแนะนำบนหน้าจอ (python.org → ติดตั้ง → ติ๊ก Add to PATH) แล้วรันใหม่ |
| พิมพ์บิลแล้วแจ้ง "พิมพ์ไม่ได้" | ชื่อเครื่องพิมพ์ผิด / เครื่องพิมพ์ปิด | เปิด `C:\print-server\print-server.env` แก้ชื่อ → รีสตาร์ท (ปิด-เปิด windows หรือรัน `print_server_http.py` ใหม่) |
| `printer_ok: false` (ขั้นตอน 4) | เครื่องพิมพ์ offline | เปิดเครื่องพิมพ์ เช็คสาย USB แล้วลอง health ใหม่ |
| เปิดเครื่อง Windows แล้วพิมพ์ไม่ได้ | auto-start ไม่ทำงาน | ดับเบิลคลิก `C:\print-server\start-hidden.vbs` ครั้งเดียว แล้วลองพิมพ์ |
| อยากเปลี่ยนเครื่องพิมพ์ใหม่ | เปลี่ยนเครื่อง/ชื่อ | แก้ `print-server.env` → รีสตาร์ท print server |

---

## สิ่งที่ควรรู้เพิ่ม

- Print Server รันที่ **พอร์ต 9120** ของคอมเครื่องนี้ — ห้ามปิด/ลบโฟลเดอร์ `print-server`
- ถ้าคอมเครื่องนี้ **เปลี่ยนชื่อ/เปลี่ยน IP** → ต้องแจ้งทีมเพื่ออัปเดตในระบบ
- ติดตั้งครั้งเดียวจบ — เปิดเครื่อง Windows เมื่อไหร่ print server ทำงานเองอัตโนมัติ
- ถ้ามีปัญหา ติดต่อทีมงาน พร้อมแจ้ง: ชื่อคอม, IP (ขั้นตอนที่ 5), และรูปข้อความ error
