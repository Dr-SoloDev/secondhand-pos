คู่มือติดตั้งเครื่องพิมพ์ความร้อน 80mm

รุ่น EasyPrint ES-8804 — สำหรับร้านรักษ์สะอาดรีไซเคิล (4 สาขา)
WINDOWS 10/11   อัปเดตล่าสุด 28 ส.ค. 2569 — เทอโบ SoloCorp OS

ก่อนออกเดินทาง — เช็คว่าเอาไปครบ
  • เครื่องพิมพ์ ES-8804 + สาย USB + อะแดปเตอร์ไฟ
  • กระดาษความร้อน 80mm 1-2 ม้วน
  • USB นี้ (มี print-server-ES8804.zip + คู่มือนี้)

ภาพรวม 5 ขั้น — ทำตามลำดับ

ขั้นทำอะไรเวลา
1ต่อฮาร์ดแวร์2 นาที
2วางไฟล์1 นาที
3ติดตั้ง (install.bat)2 นาที
4ทดสอบระบบ1 นาที
5พิมพ์บิลจริง 3 ใบ3 นาที
1ต่อฮาร์ดแวร์
  1. ใส่กระดาษ 80mm — ด้านเงาออกนอก (เอานิ้วขูดแล้วมีรอยดำคือด้านพิมพ์)
  2. เสียบสาย USB จากเครื่องพิมพ์ → พอร์ต USB เครื่อง Windows
  3. เสียบปลั๊กไฟ → เปิดสวิตช์ข้างเครื่อง → ไฟสีน้ำเงินติด + มีเสียง "ติ๊ด"
💡 ทิป: Windows จะขึ้น "กำลังติดตั้งอุปกรณ์ POS-80" ที่มุมขวาล่าง — รอให้หายก่อนไปขั้นถัดไป
2วางไฟล์ (จาก USB นี้)
  1. เสียบ USB → เปิดโฟลเดอร์ → จะเห็น print-server-ES8804.zip กับไฟล์นี้
  2. ก็อป print-server-ES8804.zip ไว้ที่ Desktop ก่อน (กันไฟล์หาย)
  3. คลิกขวา → Extract All… → เลือกที่แตกเป็น C:\print-server
    ถ้าไม่มี C:\print-server ให้สร้างโฟลเดอร์เอง: เปิด This PC → C: → คลิกขวา New Folder → ตั้งชื่อ print-server → แตกไฟล์ลงไป
  4. เปิด C:\print-server ต้องเห็นไฟล์: install.bat, print_server_http.py, print_receipt.py
3ติดตั้ง — รัน install.bat (ครั้งเดียวพอ)
  1. ใน C:\print-server ดับเบิลคลิก install.bat
  2. ถ้า Windows ถาม "Windows protected your PC" → กด More info → Run anyway
  3. หน้าต่างดำจะรันอัตโนมัติ — รอจนขึ้น Done — Print server installed (ประมาณ 1-2 นาที)
  4. อย่าปิดหน้าต่างเอง — มันจะปิดเองเมื่อเสร็จ
✅ เสร็จแล้วสังเกต: ที่ Taskbar มุมขวาล่างจะมีไอคอน Print Server หรือไม่มีก็ได้ — ไม่เป็นไร ขอแค่ขั้นถัดไปเปิดได้
⚠️ ถ้าติด Antivirus บล็อก → กด Allow / เพิ่ม Exception ให้ C:\print-server
4ทดสอบระบบ — เปิด http://localhost:9120
  1. เปิด Chrome/Edge → พิมพ์ http://localhost:9120 → Enter
  2. ต้องเห็นหน้า "Print Server Ready" หรือ {"status":"ok"}
  3. ถ้าเห็น = พร้อมพิมพ์แล้ว → ไปขั้น 5
  4. ถ้าไม่เห็น: ปิดแล้วดับเบิลคลิก C:\print-server\start.bat (หรือ print_server_http.py) แล้วลองใหม่
5พิมพ์บิลจริง 3 ใบ — ยืนยันว่าสมบูรณ์
  1. เปิด https://POS.mkxmeme.xyz → Login
  2. สร้างบิลรับซื้อใหม่: เลือกผู้ขาย → เพิ่มของ 1 รายการ → บันทึก
  3. กดปุ่ม "พิมพ์ความร้อน" → บิลต้องออกทันที
ใบที่ทดสอบดูอะไรผ่าน?
1บิล 1 รายการตัวหนังสือคมชัด ไม่จาง ไม่ขาดเป็นเส้น☐
2บิล 5-6 รายการไม่ขาดกลางหน้า กระดาษออกต่อเนื่อง☐
3บิล A4 (กดพิมพ์ A4)มี ต้นขั้ว ล่างสุดให้ฉีก — เทียบยอดบิล vs จ่ายจริง☐
✅ 3 ใบผ่านหมด = ติดตั้งเสร็จสมบูรณ์ พร้อมใช้งานทุกสาขา

แก้ปัญหาเร็ว (ถ้าพิมพ์ไม่ออก)

อาการแก้ยังไง
กดพิมพ์แล้วเงียบ1) เช็คกระดาษกลับด้านไหม 2) ถอด USB เสียบใหม่ 3) รัน C:\print-server\start.bat อีกรอบ
เปิด localhost:9120 ไม่ได้ดับเบิลคลิก start.bat แล้วรอ 3 วิ ค่อยรีเฟรช
ตัวหนังสือจาง/เส้นขาดถ่ายรูปบิลส่งให้เทอโบ — มีไฟล์ปรับความเข้มให้ทันที (threshold 120 + GS v0)
Windows บล็อก install.batMore info → Run anyway / ปิด Antivirus ชั่วคราว
กระดาษไม่ออกเลยใส่กระดาษกลับด้านแน่นอน — กลับด้านแล้วลองใหม่

โน้ตสำหรับช่าง

  • พอร์ตพิมพ์: http://localhost:9120 — POS เรียกผ่าน JS postPrintRequest('print/thermal-purchase')
  • ความกว้าง: 576 dots (80mm) — ถ้าเปลี่ยนกระดาษ 58mm ต้องแจ้ง dev
  • บิลมี ต้นขั้ว ล่างสุด — ให้แคชเชียร์ฉีกเก็บ เทียบยอด Offline ↔ Online ตอนปิดยอด
  • Log อยู่ที่ C:\print-server\logs\ (ถ้ามี)
