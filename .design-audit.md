## 🔴 Critical Issues (taste-skill violations)

### 1. Typography
- ❌ **Mitr (Google Fonts) is generic** — เหมือนทุกเว็บไทย (taste-skill: "no Inter/Roboto")
- ❌ **Missing font weight range** — มีแค่ 300-700 (taste-skill: need 500/600 Medium/SemiBold)
- ❌ **Body text default (15px)** — เล็กเกินสำหรับ data-heavy interface
- ❌ **No tabular figures** — numbers ใน tables ไม่ align (ควรใช้ monospace หรือ tabular-nums)
- ❌ **Headlines lack presence** — h1/h2 ขนาดเท่ากัน ไม่มี hierarchy ชัด

### 2. Color & Surfaces
- ✅ Orange accent (#D97706) เป็น unique identity (ไม่ใช่ purple/blue AI gradient)
- ⚠️ **Pure white backgrounds** — ควรใช้ off-white/bone (#F7F6F3) เพื่อลด harsh contrast
- ⚠️ **Shadows too heavy** — `shadow-xl: 0 20px 40px` เหมาะกับ modals ไม่ใช่ cards
- ❌ **Login gradient too vibrant** — `#92400E → #F59E0B` oversaturated (taste-skill: desaturate < 80%)
- ✅ Gray scale consistent (slate family)

### 3. Layout
- ❌ **Everything centered symmetrical** — login page, feature cards (taste-skill: break symmetry)
- ❌ **No max-width container** — content stretches edge-to-edge บนจอใหญ่
- ✅ Sidebar fixed layout OK for POS
- ⚠️ **Cards uniform height** — forced by flexbox แทนที่จะให้ organic
- ❌ **Missing overlap/depth** — elements sit flat (taste-skill: use negative margins for layering)

### 4. Interactivity & States
- ✅ Hover states exist (session ก่อนเพิ่มแล้ว)
- ❌ **No active/pressed feedback** — ไม่มี scale(0.98) on click
- ❌ **Instant transitions** — ควรเป็น 200-300ms smooth
- ✅ Loading states added (session ก่อน)
- ⚠️ **Focus ring ยังไม่ชัด** — accessibility issue

### 5. Content
- ❌ **Placeholder names generic** — "ผู้ใช้งาน 1", "สาขา 1" (taste-skill: use realistic names)
- ✅ Real business context (ร้านรับซื้อของเก่า)
- ✅ No Lorem Ipsum
- ✅ Thai language throughout

### 6. Component Patterns
- ❌ **Generic card look** — white bg + border + shadow (taste-skill: remove border OR shadow)
- ❌ **3-column equal cards** — most generic AI layout (taste-skill: avoid at all costs)
- ✅ No carousel/accordion abuse
- ⚠️ **Modal patterns standard** — ยังใช้ centered popup (taste-skill: try slide-over panels)

### 7. Code Quality
- ✅ Semantic HTML used
- ✅ CSS variables organized
- ✅ No inline styles (ลดแล้ว 60% session ก่อน)
- ❌ **z-index chaotic** — 100, 1000, 1100, 9999 (taste-skill: clean scale)
- ✅ Alt text present
- ✅ Thai meta tags

## 📋 Redesign Priority (taste-skill order)

### Phase 1: Typography (Biggest Impact, Lowest Risk) 🔥
1. **Replace Mitr** → IBM Plex Sans Thai / Noto Sans Thai (character + proper weights)
2. **Add tabular figures** → `font-variant-numeric: tabular-nums` for all numbers
3. **Scale typography** — h1: 32px → 40px, body: 15px → 16px, tighten line-height headers
4. **Add font weights** — use 500 (Medium) for labels, 600 (SemiBold) for emphasis

### Phase 2: Color Cleanup 🎨
1. **Replace pure white** → off-white #F7F6F3 for canvas, #FFFFFF for cards only
2. **Desaturate login gradient** → darker, muted oranges
3. **Lighten shadows** → reduce opacity to < 0.08 (taste-skill standard)
4. **Tint shadows** → add warm orange hue instead of pure black

### Phase 3: Layout Refinement 📐
1. **Add max-width** → 1440px container with auto margins
2. **Break symmetry** — offset stat cards, vary card sizes
3. **Add depth** → negative margins for overlapping elements
4. **Optical alignment** — adjust button text/icons by 1-2px

### Phase 4: Motion & Polish ✨
1. **Add spring physics** → replace linear easing
2. **Staggered entry** → cascade elements with 80ms delay
3. **Active states** → scale(0.98) on press
4. **Focus rings** → visible keyboard navigation

### Phase 5: Component Upgrades 🔧
1. **Replace 3-column cards** → asymmetric grid or 2-column zig-zag
2. **Remove card borders** → use only background elevation
3. **Slide-over panels** → replace some modals
4. **Skeleton loaders** → replace spinners
